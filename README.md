# Lions Club Pulheim – Website-Entwurf

Entwurf für eine neue Website des Lions Club Pulheim. **Nicht die offizielle Website** –
ein Vorschlag zur Abstimmung mit dem Vorstand.

- Richtung: "Abtei, Navy & Gold" (siehe [BRAND.md](BRAND.md))
- Statische Seite: `index.html`, `styles.css`, `script.js`, selbst gehostete Schriften in `fonts/`
- Inhalte stammen von der bestehenden Website (Stand November 2026)

## Lokal ansehen

```bash
python3 -m http.server 4392
```

Dann http://localhost:4392 öffnen.

## Offen vor einer Veröffentlichung

- Freigabe durch den Vorstand
- Verwendung des Lions-Emblems nach den Markenrichtlinien von Lions International
- Fotografie (Kaisersaal, Neujahrsempfang, Clubabende) – Platzhalter sind markiert
- Einwilligung für Namen und Porträts von Mitgliedern (DSGVO)
- Impressum, Datenschutzerklärung, Mitgliederbereich
- Ehrentafel der Abt-Wolfhelm-Preisträger und vollständige Förderübersicht
- Der Ablauf unter "Zu Gast sein" ist ein Textvorschlag und muss zum Aufnahmeverfahren des Clubs passen
